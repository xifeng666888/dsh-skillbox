QUICK GUIDE

两种用法，
都很简单。

只想装一个，复制卡片里的命令；想拥有完整市场，把公开索引添加到 DSH。

01

启用自定义索引

在 DSH 插件页启用实验功能“Custom plugin indexes”。

02

添加市场索引

进入 Discover → Manage index sources → Add index source。

03

搜索并安装
